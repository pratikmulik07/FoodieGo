    Built with the Factory Method Pattern

    Checkout asks getOrderCreator(orderType) for the right creator. DeliveryOrderCreator produces delivery orders (address required, ₹40 fee below ₹499, free at ₹499+), while TakeawayOrderCreator produces self-pickup orders (no address, ₹0 fee). The checkout code depends only on the base OrderCreator, so order types can be added without touching the checkout logic.
